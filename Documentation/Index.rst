=================
CELUM Connect FAL
=================

:Extension key:
   celum_connect_fal

:Package name:

----

A TYPO3 FAL (File Abstraction Layer) driver that exposes assets and
collections from a `CELUM <https://www.celum.com/>`__ DAM system as a
read-only TYPO3 file storage. Uses the CELUM REST API to fetch and
cache asset metadata, preview URLs, and download links.
